# Power BI — Dashboard de NovaMarket

## Objetivo

Desarrollar un dashboard para analizar el desempeño comercial de NovaMarket mediante indicadores de ventas, clientes, productos, rentabilidad y comportamiento temporal.

## Páginas del dashboard

### 1. Resumen ejecutivo

Presenta una visión general del desempeño comercial de NovaMarket mediante los principales indicadores del negocio.

Incluye:
- Ventas netas
- Órdenes totales
- Ticket promedio
- Unidades vendidas
- Ventas por categoría
- Segmentación de clientes
- Tendencia mensual de ventas

### 2. Análisis de clientes

Analiza el comportamiento de compra de los clientes y su contribución al desempeño comercial.

Incluye:
- Segmentación de clientes
- Ventas por segmento
- Relación entre ventas y frecuencia de compra
- Órdenes promedio por cliente
- Identificación de clientes de mayor valor

### 3. Análisis de productos

Evalúa el desempeño comercial y la rentabilidad de los productos y categorías.

Incluye:
- Ventas netas por categoría
- Margen por categoría
- Ventas y margen por producto
- Unidades vendidas
- Identificación de productos de mayor desempeño

### 4. Análisis temporal

Analiza la evolución de las ventas y órdenes a lo largo del periodo histórico.

Incluye:
- Evolución mensual de ventas
- Evolución mensual de órdenes
- Ventas netas por año
- Crecimiento mensual de ventas

## Herramientas

- Power BI
- DAX
- Power Query
- PostgreSQL
