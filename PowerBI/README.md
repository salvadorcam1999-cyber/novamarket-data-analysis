# Power BI — Dashboard de NovaMarket

## Objetivo

Desarrollar un dashboard interactivo para analizar el desempeño comercial de NovaMarket, integrando información de ventas, clientes, productos, categorías, rentabilidad y comportamiento temporal.

## Indicadores principales

- 4.13 mil millones en ventas netas
- 300,000 órdenes
- 10,000 clientes
- 500 productos
- 4 millones de unidades vendidas
- 25.55% de margen

## Visualizaciones desarrolladas

### 1. Resumen ejecutivo

Vista general del desempeño comercial mediante indicadores clave, ventas por categoría, segmentación de clientes y tendencia mensual de ventas.

![Resumen ejecutivo](Pagina_1_Resumen_Ejecutivo.jpeg)

### 2. Análisis de clientes

Análisis del comportamiento, valor y frecuencia de compra de los clientes, incluyendo segmentación, ventas por segmento y clientes de mayor valor.

![Análisis de clientes](Pagina_2_Analisis_Clientes.jpeg)

### 3. Análisis de productos

Evaluación del desempeño de productos y categorías mediante ventas netas, margen, unidades vendidas y relación entre ventas y rentabilidad.

![Análisis de productos](Pagina_3_Analisis_Productos.jpeg)

### 4. Análisis temporal

Evaluación de la evolución mensual de ventas y órdenes, ventas anuales y variación porcentual mensual.
